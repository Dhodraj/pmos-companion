<objective>
Build the correlation engine the whole project stands on: per-cycle-phase baselines, a 1-to-14 day
lagged cross-correlation scan, percentile bootstrap confidence intervals, and Benjamini-Hochberg FDR
correction across the candidate pair set — all deterministic TypeScript running in the WebView.

Purpose: HACK-03 is the single measurable definition of the project working, and build-plan.md §1 is
blunt about it — "if that is true at the demo, we have a project. If it is not, the other six
components are a period tracker with a nice export." The negative control matters more than the
positive one: any engine can find a pattern; this one has to be able to say there isn't one.

This is the one deliberate hand-roll in the phase. CON-BUILD-02 requires every insight to survive
"how do you know that?", which means owning the statistics line by line rather than trusting a
library's internals under time pressure. The total surface is small — roughly forty-five lines of
real mathematics across three files — and each piece is independently testable against synthetic data
with a known answer.

Output: an engine that passes both controls on synthetic data, before it ever meets Satheesh's
dataset in plan 02-06.

Owners: **Dhodraj Sundaram** leads, **Satheeshkumar** pairs from hour two (build-plan.md §3, rule
four — two people who understand it, so the demo survives Dhodraj being unavailable). Both work in
`src/core/engine/**` and nowhere else in this plan.
</objective>

  <behavior>
    - `bootstrapCI` over a strongly correlated pair of length 200 returns an interval that contains
      the sample r and excludes 0.
    - `bootstrapCI` over an independent pair of length 200 returns an interval containing 0.
    - `bootstrapCI` with n below 4 returns null — never a computed-but-degenerate interval.
    - `bootstrapCI` over a pair where one series is constant returns null rather than NaN bounds.
    - `bootstrapCI` is deterministic when handed a seeded RNG, so the same input yields the same
      interval twice in a row.
    - `benjaminiHochberg([0.001, 0.008, 0.039, 0.041, 0.042, 0.06], 0.05)` marks exactly the first
      four as significant, indexed back to the original order.
    - `benjaminiHochberg` on fourteen p-values all above 0.5 marks none significant.
    - `benjaminiHochberg` on an empty array returns an empty array without throwing.
    - `pValueFromR(r, n)` returns a two-sided p-value that decreases monotonically as |r| rises at
      fixed n, and is above 0.05 for r = 0.1 at n = 30.
  </behavior>
  <action>
    Tests first, then implement.

    `src/core/engine/bootstrapCI.ts` — `bootstrapCI(a, b, iterations = 2000, rng): [number, number] |
    null`. Percentile bootstrap: resample index pairs with replacement, recompute `pearson`, discard
    non-finite results, and return the 2.5th and 97.5th percentiles of the surviving samples. Return
    null when n is under 4, and null when more than 10% of resamples were degenerate — a
    degenerate-heavy bootstrap is the small-sample regime the confidence floor exists to catch, and
    the honest answer there is `insufficient_data`, not a wide interval. Take the RNG as a parameter
    so tests are deterministic.

    `src/core/engine/fdr.ts` — `pValueFromR(r, n): number` via the Fisher z-transform and a normal
    tail approximation, and `benjaminiHochberg(pValues, q = 0.05): boolean[]` returning a mask in the
    original index order. Walk the sorted p-values from the largest rank down, find the largest rank
    where p ≤ (rank/m)·q, and mark every p-value at or below that rank as significant. Handle the
    empty array and the all-non-significant case without throwing.

    Multiple-comparison correction is not decoration here. Scanning fourteen lags across a dozen
    candidate pairs is over a hundred and fifty tests; without FDR the engine would find something
    every time, and the negative control — the part the pitch actually rests on — would be
    unreachable.
  </action>
  <verify>
    <automated>npx vitest run src/core/engine/bootstrapCI.test.ts src/core/engine/fdr.test.ts &amp;&amp; npx tsc --noEmit</automated>
  </verify>
  <acceptance_criteria>
    - `bootstrapCI` excludes 0 on a correlated pair and includes 0 on an independent pair.
    - `bootstrapCI` returns null below n = 4 and on a constant series, and is reproducible with a seeded RNG.
    - `benjaminiHochberg` marks exactly the first four of the documented six-p-value case and none of fourteen weak ones.
    - `benjaminiHochberg([])` returns `[]`.

    movement_minutes→mood, movement_minutes→energy, stress→skin_severity, stress→digestion,

    `src/core/engine/index.ts` — rewrite `runFindings` to compose the real pipeline while keeping its
    signature and every call site untouched:
    1. Pivot rows to day-aligned series per dimension and residualise against `phaseBaselines`.
    2. For each candidate pair, `scanLags` over 1..14 on the residualised series.
    3. If paired observations at the best lag are below `MIN_PAIRED_OBSERVATIONS` (20), return

       is explicit that a bootstrap below the floor produces garbage bounds, and the confidence floor
       exists precisely to catch that regime.
