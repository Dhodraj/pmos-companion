<objective>
Ring 4: the safety layer. PHQ-4 and GAD-2 running from fixed clinician-written copy, and immediate
escalation to Tele-MANAS 14416 on any suicidality or self-harm response — with zero generated text
anywhere on the path and zero network calls from it.

Purpose: HACK-07 is ring 4. The constraint on it is the only rule in build-plan.md §11 stated with no
exceptions — "nothing on a crisis path is generated. Fixed text, real numbers, written in the
pre-week." PROJECT.md puts it more plainly: one mishandled crisis ends the product. SAFE-03 adds that
crisis resources are never paywalled, login-gated or rate-limited, which in this build means the
crisis screen must be reachable and functional with no account, no network and no state.

This is also cut-list item 3. Under that cut "the UI comes off and the logic stays with one slide" —
so the slide is written here, now, while there is judgement available to write it, not at hour
twenty-eight.

Output: a screener, an escalation path that always works, and the slide that replaces the screens if
the cut is called.

Owner: **Belson Johnson**, all three tasks, pasting pre-written clinical copy — build-plan.md §8 puts
"Safety layer screens, pasting pre-written copy" in his H22–H28 block precisely because pasting is
mechanical and hour twenty-two is not the time to be composing clinical language.
**Satheeshkumar** wrote and fixed that copy in the pre-week (build-plan.md §7, Wed 5) and does the
content QA pass on it in the same block. Nobody writes new clinical wording during the build.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| screener response → escalation | A person in crisis and the app's reaction to them |
| safety layer → network | The boundary that must not be crossed at all |
| copy module → screen | Clinician-reviewed language must reach the user unaltered |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-02-53 | Tampering | Generated or paraphrased text on a crisis path | critical | mitigate | `SAFETY_COPY` is deeply frozen with no interpolation, no string-returning function and no `.replace`; automated gate rejects any of those; rendered strings are asserted verbatim against the module |
| T-02-54 | Denial of Service | Crisis resources unreachable without network, login or state | critical | mitigate | `CrisisScreen` renders cold with no props and no state; the zero-fetch spy fails the suite if any call is attempted; verified in flight mode on the demo phone |
