<objective>
Put the two documents this phase produces in front of the person who has to believe them. The
doctor one-pager and the "how do you know that?" explanation are only worth what a clinician reading
them in a real seven-minute consultation says they are worth — and this is the plan where that is
measured rather than assumed.

Purpose: the phase's whole claim is that eighteen months of lived experience becomes evidence a
clinician accepts. Every earlier plan verified that the numbers are right and the document renders.
None of them verified that the document works on a person under time pressure, or that the method
text says the same thing the method does. This closes both, and it is also the last chance to change
fixed copy before it reaches a user.

Output: a reproducible review pack, a written acceptability rubric, the recorded review, and the
copy corrections applied.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Synthetic review data → review directory | The pack must contain no real user data; it is generated from a seed. |
| Reviewer corrections → fixed strings | Text a clinician reviewed becomes text a user reads; a later edit can silently revert it. |
| Method text → engine behaviour | A description that drifts from the code makes "how do you know that?" a false answer. |
