<recorded_assumptions>
These are decided here, not left open. Plan 01-05 inherits them.

1. **"Capacitor 6" in ADR-001 is a literal pin, not shorthand for current Capacitor.** All four
   Capacitor packages install at the `latest-6` dist-tag, resolved this session as **6.2.1**. A bare
   `npm install @capacitor/core` today resolves to 8.5.0, two majors ahead, with a 9.0.0-alpha
   channel already live. Silent drift here is how the weekend's build breaks.
2. **React is pinned to the 18 line (18.3.1), per ADR-001's literal "React 18".** The registry's
   `latest` is 19.2.8; this phase does not adopt it.
3. **TypeScript is pinned to the 5 line (5.9.3), not the 7 line.** TypeScript 7 is a native-port
   rewrite. Adopting it four days before a hackathon is an uncosted risk with no stated benefit.
4. **Vite 6.4.3 with `@vitejs/plugin-react` 4.7.0**, the newest Vite line carrying a stable
   React-18-compatible plugin. Tailwind pins to the 3 line (3.4.19); Tailwind 4 replaces the config
   model entirely.
5. **The tracer's `Finding` is a real two-variant discriminated union with a provisional field
   list, not a mock.** The file path, the barrel, the `status` discriminant and the `assertNever`
   pattern are architecture and survive to production. Only the field list is filled in by plan
   01-05. That is a functionality gap, not an architectural gap.
6. **`pre-event-scaffold` is not a throwaway branch — it is the phase's integration branch, and it
   is never merged into `main` before the weekend.** Every line of pre-event engineering lands on it:
   this plan's toolchain, plan 01-04's dry-run document, plan 01-05's frozen types, plan 01-06's
   fixtures and insight card, plan 01-07's generator. Local `main` stays byte-identical to
   `origin/main` plus plan 01-03's single PROPOSAL.md correction, and nothing else. The alternative
   — fast-forwarding the scaffold into local `main` so everyone works there — was considered and
   rejected: it puts unreviewed, possibly-not-yet-permitted pre-event code one routine
   `git push origin main` away from the public org repo, which is exactly the accident T-01-01 and
   plan 01-02's T-02-03 exist to prevent. Keeping the two lines of history apart makes plan 01-03's
   push provably one commit wide. Task 4 records this and every plan downstream asserts it.
</recorded_assumptions>
