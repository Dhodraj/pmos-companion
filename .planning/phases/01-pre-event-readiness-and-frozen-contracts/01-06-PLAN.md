`src/types/` compiles. This asserts that the person who has to build six screens against it can do so
without one conversation.

Belson takes the frozen barrel and hand-written fixtures, and builds the insight card — the screen
build-plan.md section 5 names as having the most dependents, and the one the demo's fourth beat rests

honesty of the whole product lives in that field. If it renders as a pattern card with three empty
slots, the freeze bought nothing a user can see.

section 2 and nobody else writes in it.

   protects. `src/ui/` is Belson's directory, so the fixtures sit with the person who maintains them.

   the type with the most dependents and both of its variants. Building all five screens now would
   consume Belson's Saturday budget on work the cut list may remove anyway.

   proceed without an answer, he stops, writes the question down, and the checkpoint records it. A
   blocked task that names its blocker is a successful measurement; a task completed by quietly asking
   is a failed one.
4. **This plan shares one working tree with plan 01-07, on the branch `pre-event-scaffold`.**
   `health-team-311-war-room` is a sibling checkout outside GSD's worktree isolation, so the two
   wave-5 plans cannot each get their own copy. They are safe together because neither moves HEAD
   and their file sets are disjoint — `src/ui/` and `src/App.tsx` here, `tools/` there — and because
   each stages explicit paths. The one shared resource that is not disjoint is `node_modules`: plan
   01-07 task 1 installs `seedrandom`, and that is the only dependency change permitted in this
   wave. If this plan's build or test run happened to straddle that install, re-run this plan's
   verify rather than reasoning about which half of the install it saw.
