# Archive — superseded explorations

Nothing here is being built. Kept because the *reasoning* is reusable — each folder records a direction that was tested and set aside, and why.

| Folder | What | Why archived |
|---|---|---|
| `idea-reports/` | Three ranked idea reports: **health-india-pain-breadth** (RxLekha, Sehat Copilot, ParentCare…), **health-india-complex-unsolved** (PolyGuard, ShelfSense, MetaTwin…), **four-track-portfolio** (Theervu, OruKural, Sollu…) | Pain-breadth ideas read as obvious AI wrappers; complex ones still weren't zero-to-one. Useful competitor/tarpit analysis and the YC-framework scoring survive. |
| `frontier-bets/` | **PulseSight** (contactless vitals from face video, rPPG) · **StethoPhone** (AI stethoscope from a bare phone mic) | PulseSight is already commercialized (NuraLogix Anura is FDA-cleared and does vitals-on-video-calls; Binah.ai SDK; several open-source rPPG toolboxes). StethoPhone is genuinely less crowded but needs a passive coupler — failed the "absolutely no add-on" bar. Both specs are still viable if revisited. |
| `civic-track/` | **KAAVAL** (offline maternal risk-triage) + five civic one-pagers (Theervu, OruKural, Sollu, Nilai, Kanakku) | Strong civic-tech work, but Tamil-Nadu-specific and framed around rural frontline workers — narrower than the scalable consumer product we wanted. |

Corresponding raw research lives in `../research/` (one folder per workflow run).

Verified framing: SDG-aligned tracks, example builds inspired by YC's Requests for Startups, winners piloted in real constituencies/local markets with TiE Kovai + Startup Culture.
